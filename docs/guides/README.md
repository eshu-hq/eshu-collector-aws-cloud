# Guides

Task-shaped help for the AWS Cloud collector. There's no
service to run; these guides cover the image, seeding,
grants, and reading what each run leaves behind.

| Guide | Use it when |
|---|---|
| [Operate](operate.md) | You're building the image and reading a run's health line, exit code, and statuses |
| [Troubleshoot](troubleshoot.md) | A run fails fast, comes back partial, or keeps timing out |
| [Seed](seed.md) | You're installing the collector where the host expects, and sorting producer grants |
| [Release](release.md) | You're cutting a version and re-pinning digests |

For the ideas behind these guides, see
[concepts](../concepts/README.md). For every field and fact
kind, see [reference](../reference/README.md).
